# Aprender a cambiar · Historia y práctica de la TCC

Sitio educativo de una sola página, en español rioplatense, sobre la historia y, sobre todo, la práctica clínica de la **terapia cognitivo-conductual (TCC)**: de Pávlov a la terapia basada en procesos. Cada modelo terapéutico se presenta con las mismas seis preguntas (qué mantiene el malestar, qué es mejorar, por qué funcionaría, qué se hace en sesión, un caso y qué dice la evidencia), con diagramas que se arman a medida que se scrollea.

**Ver online (URL prevista):** https://pasquinell.github.io/tcc_terapia/

> Material educativo. No es un tratamiento ni reemplaza la consulta con un profesional de la salud mental.

## Estructura

- `index.html`: el sitio completo (HTML, CSS y JS en un solo archivo, sin build).
- `img/`: retratos con licencia libre (ver abajo).
- `.nojekyll`: hace que GitHub Pages sirva los archivos tal cual.
- `doc/README.md`: documentación técnica (cómo está armado, decisiones, fuentes, cómo editar y verificar).
- `doc/tools/`: scripts de verificación.
